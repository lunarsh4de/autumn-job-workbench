# 投简历助手 0.12.2

面向 Microsoft Edge 和 Google Chrome 的 Manifest V3 扩展。它识别招聘网页中的空白字段，填写本地保存的资料，并由用户核对后手动提交。

## 主要功能

- 首屏先上传并解析简历，预览分类结果后再保存；一键填写姓名、电话、邮箱、城市、学历、学校、技能、主页和自我介绍，保留网页已有内容。
- 填写前预览识别结果，区分“将填写、保留现有、资料缺失、选项不匹配”。
- 明确识别到唯一简历控件时选择本地附件；已有附件、格式不符或控件不明确时跳过。
- 撤销当前页面最近一次填写；已被用户修改的字段会保留，附件和网站已接收的数据不会撤回。
- “投递 / 资料 / 记录 / 经历”四标签界面，显示资料完成度、简历状态、当前网站和最近 30 条投递记录；最多保留 500 条，记录页支持投递明细与公司汇总 CSV 导出和清空。
- 资料与附件保存在 `chrome.storage.local`，支持 JSON 备份与恢复，不接入第三方 API。
- 在岗位页按 `Alt+Shift+F` 或使用网页右键菜单即可快速填充；结果会显示在页面悬浮提示和扩展徽标中。

## 0.12.2 自动记录失败补救

- 自动记录写入失败时，页面悬浮助手会显示明确原因，并提示点击“标记已投递”手动重试。
- 状态提示会在需要时自动挂载悬浮助手，避免页面尚未渲染悬浮入口时用户看不到失败说明。
- 增加随机公司域名、DJI/Moka、公司元数据和存储失败路径测试。

## 0.12.1 公司记录识别修复

- 修复招聘平台将 `Moka`、`Mokahr` 等通用平台名写入公司记录的问题。
- 修复公司元数据首尾空格导致公司汇总出现重复名称的问题。
- `apply.careers.dji.com` 等招聘域名在没有有效公司元数据时归一化为 `DJI`。

## 0.12.0 已投公司与记录导出

- “记录”页同时提供最近投递明细和“已投公司”汇总，可查看每家公司投递岗位数、已确认投递数、最近投递时间和岗位名称。
- 提供“导出记录”和“导出公司”两个 CSV：明细包含时间、岗位、公司、状态、记录方式和链接；公司汇总包含岗位数、确认数、最近时间和岗位列表。
- 记录保留上限由 30 条提高到 500 条；界面仍展示最近 30 条，统计和导出使用全部有效记录。
- 对 DJI 招聘域名进行公司名称归一化，已有 `apply.careers.dji.com` 记录会按 `DJI` 汇总。

## 0.11.0 比赛年份与校园经历

- 文字识别新增校园经历：支持校园实践、学生工作、学生干部、社团经历、社会实践和课外活动等栏目。
- 校园经历保存组织/活动、担任职务、开始时间、结束时间和经历内容，并支持多个条目。
- 获奖记录保存奖项名称、独立获奖年份和说明；比赛记录保存赛事名称、比赛年份或开始/结束时间、角色和描述。
- 单独写成“2024 年”的多个比赛或奖项会按年份拆分，不会合并成一条。

## 0.10.0 DJI / Moka 兼容与投递记录

- 针对 DJI 使用的 Moka 表单增加深层视觉标签识别，支持教育、实习、项目、赛事、获奖、校园经历、语言、论文/期刊字段。
- 支持“语言证书及成绩”等合并文本框；照片和作品附件始终不会被简历附件自动选择。
- 用户点击提交后，只有页面出现新的明确成功状态才自动记录岗位；不会因“预览并提交”按钮本身提前记录，24 小时内同 URL 去重。
- 记录只保存在本地，展示岗位、公司或站点、状态、时间和链接，可导出 UTF-8 BOM CSV；清空前必须再次确认。

## 0.9.0 简历分类与多段经历

- 工作经历、教育经历和项目经历改为结构化列表，每类最多 20 条，可在“经历”页添加、编辑和删除。
- 支持从 PDF、DOCX、TXT 本地读取简历，并自动分类基础资料及三类经历；解析结果先预览，确认后才写入。
- 导入时默认保留已有资料并追加不重复经历；勾选“替换已有经历”后才覆盖。
- 3 MB 内的 PDF/DOCX 可在确认导入时同时保存为投递附件。用于分类的文件最大 10 MB，PDF 最多解析 40 页。
- 对招聘网站已经提供的多段经历字段，按页面顺序填入第 1、2、3 段；只有一个经历大文本框时会合并全部条目。
- 备份升级到 schema v3，继续兼容 v1/v2 备份。

### 0.9.1 分类兼容修复

- 支持“英文姓名 + 中文姓名”位于同一行的双语简历，优先提取中文姓名。
- 支持没有“教育经历”标题、直接把学校信息放在页首的简历。
- 修复“学校一行 + 专业/学位一行 + 日期一行”布局导致的学校、专业错位。
- 支持“岗位匹配与专业技能”等复合技能标题。

### 0.9.2 随机操作与读取稳定性

- 选择新简历前立即清除旧分类候选，损坏文件失败后无法误应用上一份结果。
- 并发读取采用“最后一次选择生效”，较慢的旧文件不能覆盖新文件。
- “专利与奖项、证书、语言、校园经历”等栏目会作为独立分类或边界，不再污染最后一段项目描述。
- 支持带编号、项目符号和中英文后缀的常见栏目标题。
- 增加可复现随机测试：200 种简历布局、1000 个噪声/损坏文本、20 轮字段乱序及 40 步随机经历操作。

## 0.8.0 快捷填充改进

- 新增 `Alt+Shift+F` 快捷键和“用投简历助手快速填充”网页右键菜单。
- 快捷入口默认只填写文字资料，不会选择简历附件。需要时可在“资料”页主动开启“快捷填充时选择附件”。
- 快捷入口同样按需注入当前 HTTP(S) 页面，不申请永久网站访问权限，也不会点击最终提交。
- 资料备份升级到 schema v2 并包含快捷附件设置；旧版 v1 备份仍可导入，缺省设置按关闭处理。
- 后台操作以扩展徽标反馈填写数量或错误，页面内仍会显示详细结果。

## 0.7.0 安全和兼容性改进

- 移除 `<all_urls>` 常驻权限和全站内容脚本，改为点击扩展后通过 `activeTab + scripting` 注入当前网页。
- 安装后已打开的普通网页无需刷新；首次预览、填写或撤销时会自动注入并重试。
- 网页悬浮助手使用 Shadow DOM，降低招聘网站 CSS 导致错位、隐藏或样式污染的概率。
- 内容脚本重复注入具备幂等保护，不会重复注册消息监听器。
- 空资料首次打开会直接进入设置页，不会让用户先面对无效的填充按钮。
- 修复 Windows PowerShell 5 读取中文 Manifest 时的编码错误。

完整审查结论见 [SECURITY_COMPATIBILITY.md](SECURITY_COMPATIBILITY.md)。

## 快速安装到 Edge

1. 解压发布包，不要直接在 ZIP 内运行文件。
2. 双击 `安装插件.cmd`。安装前会明确提示“必须开启开发人员模式”，随后校验文件、复制到固定目录，并打开 Edge 扩展页面、安装向导和目标文件夹。
3. 在 `edge://extensions/` 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择助手打开的 `%LOCALAPPDATA%\ResumeQuickApply\Extension` 文件夹。
5. 将“投简历助手”固定到工具栏，首次打开后填写资料并选择简历。

Edge 不允许普通脚本静默安装未上架商店的扩展，因此第 3、4 步必须由用户完成。安装助手已经将人工步骤压缩为浏览器内的一次安全确认，不需要管理员权限，也不会修改浏览器策略。真正的一键安装只能在发布到 Microsoft Edge Add-ons 商店后实现；通过注册表或企业策略强装会带来管理员权限和安全风险，本项目不采用。

更新时再次运行 `安装插件.cmd`，然后在 Edge 扩展管理页对该扩展点击“重新加载”。安装路径保持不变，扩展 ID 和本地资料不会因为复制更新而主动改变。

## 手动安装

1. Edge 打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
2. 开启开发人员模式，点击“加载解压缩的扩展”。
3. 选择包含 `manifest.json` 的 `resume-quick-apply` 文件夹。

安装后打开招聘网页，点击扩展图标，或按 `Alt+Shift+F`、使用网页右键菜单。插件只在这次用户操作授权的当前标签页运行，不会在所有网页后台常驻。刷新或打开新标签页后，需要再次主动触发。

## 数据和附件

资料未额外加密。备份 JSON 包含个人资料、结构化经历和完整简历附件，应像原始简历一样妥善保管。附件支持 PDF、DOC、DOCX，最大 3 MB；分类导入支持 PDF、DOCX、TXT，旧版 DOC 请先转换为 DOCX 或 PDF；导入备份最大 5 MB。文件头校验用于发现格式不符，不能证明文件完整或无害。

简历分类使用本地规则，不会联网或上传，但不同模板的栏目和排版差异很大。分类结果不是事实认证，必须在预览和经历页中检查公司、职位、日期等字段。

选择附件并触发网页的 `change` 事件可能让网站立即上传。插件不会点击最终提交按钮；“已选择附件”不代表网站已经接收或申请已经完成。请检查页面结果后手动提交。

## 已知边界

- iframe、封闭式 Shadow DOM、自定义下拉框、复杂富文本、验证码和多步表单可能需要手动处理。
- 插件会填充网站已经存在的多段经历输入框，但不会自动点击“新增工作/教育/项目经历”按钮；槽位不足时需用户先在网站中添加。
- 扫描版或图片型 PDF 没有可提取文字，当前版本不做 OCR；请改用可复制文字的 PDF、DOCX 或 TXT。
- 网站可能在插件短时检查后异步更改字段；“已填写”不是服务器验收结果。
- 悬浮入口在当前网页被按需注入后才会出现；刷新页面后需要再次点击扩展。
- 多个简历上传框、已有附件或不支持的格式会跳过自动选择。
- 快捷键可能与系统或其他扩展冲突，可在 `edge://extensions/shortcuts` 中修改。
- 不处理验证码、自动提交或批量海投。
- 开发人员模式可能被企业策略禁用；Firefox、Safari 和移动浏览器不在当前支持范围。
