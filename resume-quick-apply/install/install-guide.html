投简历助手安装向导

安装文件已经复制，Edge 扩展页面和目标文件夹也已打开。

重要：本地版必须先开启 Edge“开发人员模式”，否则“加载解压缩的扩展”按钮不会出现。
1
在 Edge 扩展页面开启“开发人员模式”开关通常位于页面左侧或右上角。
2
点击“加载解压缩的扩展”这是 Edge 安装本地开发版扩展的标准入口。
3
选择安装助手打开的 Extension 文件夹
%LOCALAPPDATA%\ResumeQuickApply\Extension
4
将扩展固定到工具栏打开 Edge 的扩展菜单，点击“投简历助手”旁的固定按钮。首次打开会直接进入资料设置。
Edge 不允许本地程序静默安装扩展，因此最后的“加载解压缩的扩展”必须由你亲自点击。安装助手不需要管理员权限，也不会修改浏览器策略。

完成后打开招聘网页，点击扩展图标进行设置和预览；也可按 Alt+Shift+F 快速填充。
