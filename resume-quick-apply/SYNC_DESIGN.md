# 插件与网站协作设计 · 0.18.0

日期：2026-11-04。这里的场景是产品经理视角的模拟走查，不代表已进行真实用户访谈。

## 用户路径

1. 在 BOSS 或其他招聘页，用插件记录岗位或识别明确投递成功。
2. 点击插件「工作台」打开配套网站；首次点「连接插件」。此时合并两边已有岗位，额外保留网页连接前快照。
3. 网站显示同步数量和时间。看板改阶段、补备注、调整面试/跟进时间后先本机保存，再写回插件。
4. 网站关闭期间，插件照常记录；下次打开网站或切回网页时补齐。插件不可用时保留待同步修改，重连重试。
5. 定期点击「完整备份」下载 JSON，包含所有岗位与日程；需要迁移时通过「恢复备份」合并。

## 模拟需求与问题处理

| 使用情境 | 用户担心的问题 | 实现 |
|---|---|---|
| 一天连续在 BOSS、公司官网记录 | 网站没开，会不会漏记 | 插件先持久保存；网站连接/回到前台/30 秒可见页检查补齐 |
| 同岗位从不同推荐链接进入 | 产生两条数据 | ID 或规范化 URL 识别，移除常见跟踪参数 |
| 网站拖到面试，插件补备注 | 谁覆盖谁 | 字段补丁；保留面试阶段和独立备注 |
| 两个网页同时改备注 | 一段内容无声消失 | 合并双方片段并提示；每方最多 4900 字，合并仍遵守 10000 字上限 |
| 两处改同一个非备注字段 | 值来回变化 | 后台收到的最后一次修改为准；同步结果显示冲突提示 |
| 插件禁用/连接过期 | 保存是不是失败了 | 本机持久 outbox，显示待同步数量与刷新新版插件的指引 |
| 同步成功但响应丢失 | 重试会不会重复创建 | 操作 ID 去重（最近 4000 次），URL 再去重 |
| 网站删岗位，旧页面稍后联网 | 刚删的岗位又出现 | 删除标记阻止旧编辑和自动信号恢复；主动新建/恢复备份可恢复 |
| 清空插件历史 | 网页又把历史补回来 | 同时清除对应看板岗位，记录删除标记，确认框说明影响 |
| 第一次连接已有网站记录 | 插件会不会直接覆盖 | 按岗位合并、较新编辑优先，并保留连接前快照 |
| 编辑表单期间其他标签同步 | 未改过的字段覆盖新数据 | 表单只提交相对打开时真正改变的字段；岗位已删除时阻止保存 |
| 想换电脑或清理浏览器 | 没有完整备份 | JSON 导入导出，保留备注和日程；CSV 用于阅读与统计 |
| 手机窄屏访问 | 按钮拥挤、页面横向漂移 | 同步区上下排列、操作换行；表格在容器内横向滚动 |

## 数据与权限

插件 `chrome.storage.local` 是连接后的统一持久源，网站 `localStorage` 保存快照和 outbox；公开岗位库仍使用 IndexedDB 和公共 `jobs.json`。后台串行处理录入和同步，只传岗位字段及简历档案标签，不传基础资料、联系方式、经历或附件。不新建服务器、云账号或令牌。

常驻桥只在本项目 Pages 路径生效。页面与隔离内容脚本通过同窗口同源 `postMessage` 请求/响应，内容脚本再调用扩展后台。后台校验发送方和顶层路径；无连接授权时只有状态信息。断开会停止同步并保留缓存。每次同步会归一化字段和限制批量数量。

工作台最多 1000 个岗位；插件历史最多 500 条有有效网页链接的岗位。无链接岗位可在网站跟踪。Web Locks 支持同源多标签页串行提交；不支持该 API 的旧浏览器建议单标签页编辑。相同浏览器配置文件可同步；不同电脑、不同浏览器、无痕窗口之间不自动同步。

仅借鉴功能和交互概念，本轮没有复制这些项目源码，也没有加入其 AI 服务、Gist 凭证或联网简历处理。

## 验证范围

- Node 测试包含真实项目页面客户端、隔离桥脚本、后台处理函数的消息链路，Chrome 存储 API 为模拟实现；覆盖首次合并、双向同步、断开补传、并行字段、冲突备注、重试、删除、恢复和来源拒绝。
- 本机 Edge UI 检查网站无桥接时仍可新增岗位、刷新后保留、显示待同步数量，并检查桌面与窄屏布局。界面证据使用明确标记的模拟岗位。
- 安装助手执行 ValidateOnly；安装目录复制与 ZIP 内容校验是文件验证，不能替代 Edge 手动重新加载。
- 本轮不自动绕过浏览器扩展管理页访问限制；真实已启用扩展与线上新版页面的最终连接，需要新版网站部署和浏览器扩展刷新后验证。
- BOSS 真实在线简历导入仍未取得页面加载完成后的端到端证据。

## 公开发布集成补充

发布基于远端主分支最新提交，保留已有的外企筛选、简历本地上传与自动匹配、个人中心、键盘焦点恢复、投递跳转确认与可选 GitHub Gist 备份。原有 GitHub 主站与 API 权限仅供用户主动登录备份使用；岗位同步桥不读取或传输令牌及简历内容。公开岗位源重试与部分源失败继续发布的逻辑保留。
