# 微信分享文案

最近把自己用的「投简历助手」和网页升级成了「智能求职工作台」。

找岗位、筛方向、按公司折叠、整理投递进度，现在可以放在一个地方；插件负责解析简历、预览填表，网站支持 GitHub 登录保存申请记录，公开岗位每天定时更新。

这次还加了批量任务：填自己的 API Key、选模型和岗位，按 JD 生成招呼语，逐项审核后再确认执行，并保留每项结果。首版面向可识别的 BOSS 沟通页和 Moka 官网最终申请表，遇到验证码、缺附件或未适配页面会暂停。自动执行目前通过模拟页面验证，真实站点仍需谨慎试用。

做这个工具，是想少花一点时间重复填资料，多留一点时间准备作品集和面试。欢迎试用，也欢迎提问题。
